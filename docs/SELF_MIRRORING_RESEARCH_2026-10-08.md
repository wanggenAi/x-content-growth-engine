2026-10-08（Asia/Shanghai）。模型为 `SELF_MIRRORING_V1 / HYPOTHESIS`。

## 本轮真正发现了什么

1. **自己的记录尚不能证明“心理账户强 → 传播好”。** 对2026-10-04已有18条近期快照与4条独立详情记录按URL去重，得到21条自帖。相对阅读较高的独立复看对象包括就业分项C204、发绣C291、居里奖项纠错C016、倒赞机制C201；四条均未出现可见赞、回复或转发。这是低量便利样本的描述，不是成功案例集。
2. **距离近不是必要条件。** C016没有明显收入、职业或人生处境接口；C291也不是多数读者亲历的职业，仍位于这批快照的相对较高位置。常识纠错、陌生物件、制作时间也可能成为入口。不能把“普通读者不是这个人”直接判成没有价值。
3. **真实筹码和公平冲突不是充分条件。** 同批相对较低阅读的C282（爱好与家庭补助）、C284（养老恐惧）、C289（福利与工作期限）、C297（生活费与联系）均有心理接口。C289、C297有具体数字及真实判断分歧；结果仍不能支持它们天然获得传播。缺少读完率、分发入口、同窗口基线，无法判定究竟在哪一环失败。
4. **表达与转发需要分别研究。** 外部V24/V25等资源样本有直接保存、使用或转发入口，但正文未必刺激评论。把七个因素都当作必须为高、或者相乘为成功概率，会误杀有用材料。
5. **“留下最后10%”目前没有自己的结果支持。** C204/C291/C201都已经提供解释；C289/C297保留更多判断空间，尚未显示因此获得有效互动。观点空间是待检验变量，不能为了评论删去必要事实、隐藏答案或故意说错。

原始账号数字与页面材料仅存ignored `data/private/content_review_2026-10-04/`；本轮私有输出在 `data/private/self_mirroring_2026-10-08/`。公开只保留链接、编辑判断和限制。保存时间不是精确捕获时间，21条记录的精确捕获时间均缺失，不能把这些累积快照回填成24h反馈。

## 模型契约

人表面上在看别人，很多时候实际上在看自己；这是研究入口，不是所有阅读的解释。

| 概念 | 本轮操作定义 | 必须保留的边界 |
| --- | --- | --- |
| SELF-RELEVANCE / SELF-MIRRORING | 谁通过利益、身份、恐惧、欲望、判断、过去或未来与材料连接 | 属于编辑推断；须说明具体人群和心理接口 |
| PSYCHOLOGICAL ACCOUNT | 读者在意的筹码、触发它的文字线索、可能出现的内心话 | 标签不足；每个账户保存stake/cue/reader_thought；可以扩展账户 |
| SELF-RELEVANCE DISTANCE | 年龄、收入、职业、城市、身份、人生阶段、经验、利益八项距离及bridge | 未知null；崇拜、梦想、投资、价值观可跨越人口距离；不按近远打总分 |
| MATERIAL STRENGTH | 事件/原料里的真实数字、动作、对话、变化、损失或资源交付 | 与topic_strength分开；本轮未测题材热度，topic_strength保持UNKNOWN |
| EXPECTATION VIOLATION | 哪个A→B预期被具体A→C材料打断 | 不为了制造反差扭曲原事实；资源型材料可无强反转 |
| OPINION ACTIVATION | 不靠CTA，读者凭自己的知识、经验或判断想补什么 | 预测不是评论；不能故意错误、仇恨或谣言诱骗纠错 |
| OPINION SPACE | 事实和关键证据交付后仍真实存在的经验、解释或价值分歧 | 不是假悬念；不替读者做最后判断，也不藏必要信息 |
| SOCIAL CURRENCY | 会发给哪个具体人，对方为什么需要/会有什么反应 | 找不到接收者则G层降低；不把“所有人”当对象 |
| PREDICTED INNER RESPONSE | 进入正式稿前，读者可能自动出现的第一句话 | “哦/知道了/挺有道理”会触发弱稿原因；强烈措辞本身不算证据 |

14个初始账户：自我位置、公平、利益、未知、预期违背、隐藏规则、体面尊严、地位变化、身份、自我判断、欲望恐惧、后悔、控制感、社交货币。代码不把这个列表封死；新账户也要填具体筹码、线索与内心话。相对位置和地位变化值得检查，但不是实测因果变量。

12个表达入口：身份被触及、自身经验、观点冲突、公平判断、道德判断、原因解释权、预测、归因、展示知识、展示经历、展示身份、纠错。真实评论分类另用 `PERSONAL_EXPERIENCE / DISAGREEMENT / AGREEMENT / IDENTITY_SIGNAL / CORRECTION / MORAL_JUDGMENT / EXPLANATION / QUESTION / TAG_OR_SHARE_INTENT / HUMOR / OTHER`，允许同一回复多类，保留父帖链接、评论链接、UTC、证据与分类理由。agent检查不冒充human_reviewed。

七因素乘法表达只保存为工作假设：Self-Relevance × Psychological Stakes × Expectation Violation × Concrete Scene × Information Gap × Opinion Activation × Social Currency。**不计算数值乘积，不给曝光概率，不自动升级F01–F05。** HIGH/MEDIUM/LOW是编辑序数判断，UNKNOWN代表不知道；不是量表测量，也不宣称跨审稿人可比。attention_mechanism和acceptable_editorial_mechanism分别存储；高浏览中含未核统计、群体归因、隐私侵犯建议、权利不明资源和效果承诺的案例保持RESEARCH_ONLY。

## 生产链如何调用

沿用现有 `validate_candidate()`，新增必填reader_model；旧记录缺模型时不再自动满足新闸门。已发布记录不会被重写或重新发布。C355只增加明确标为发布后的回顾标注，不把新理论倒填成原预注册。

`review_profile()`输出A材料、B自我映射、C筹码、D反差、E场景、F表达、G转发、H证据、I新颖性的弱项与`REVIEW_FIRST / LOWER_PRIORITY / HOLD_NEEDS_ANNOTATION`，不返回总分。任何LOW/UNKNOWN降低优先级；结构摘要不能进入生产证据，研究专用机制和重复材料不能过闸门。材料/自我映射/筹码极弱、被动内心回应、REPLY缺表达或SHARE缺转发接口会阻止通过。缺反转的有用资源仍可在审核中降低优先级而非一刀切淘汰。人工来源核对、单一primary_action、novelty与预注册继续有效。

顺序是：比较发现的材料 → 检查心理筹码 → 明确哪个中文读者为什么在意 → 预测内心第一句 → 明确转给谁 → 核事实/权利/新颖性 → 写稿/人工审核。标注只给证据与判断，不产生“一人—结果—没想到”的句式模板。

C355已经是SHARE主动作的单条实验；只观察原问题，不为迎合新模型改成REPLY实验。1h、6h已到但没有对应记录，标`DUE_MISSING`；24h、72h、7d按真实发布时间计算。将来的严格模型回测采用窗口到点后15分钟内捕获、人工复核、同一正文摘要哈希和证据来源；晚到的累积数字另存探索快照，不能回填过去。该容差是本轮对未来数据的约定，不假装在C355原预注册时已有。

独立计算replies/views、reposts/views、likes/views；analytics的impressions另算，不与views混为同一分母。缺失或0分母返回null，真实0互动保留0。bookmarks/profile_visits/follows不可见则null。无归因关注数据，不推断关注改善；无固定窗基线，不算相对提升。

## 可重复运行与校验

```sh
python3 scripts/build_reader_recode.py
python3 -m growth_engine import-reader-annotations data/reader_model_annotations_2026-10-08.json
python3 -m growth_engine reader-packet --kind material
python3 -m growth_engine reader-review path/to/material_or_candidate_array.json
python3 scripts/backtest_reader_history.py
python3 -m unittest discover -s tests -v
python3 -m growth_engine audit
```

JSON为可复现派生种子，SQLite为ignored本地查询副本；同实体/版本幂等导入，修订追加版本，同版本冲突整批回滚。research-packet JSON和reader-packet均可输出完整字段，editorial-gate调用同一模型校验。评论校验用reader-comments，实际原文与账号指标文件保持私有。新公开clone可以重建标注；没有本地私有证据时不能重建账号回测数字。

本轮没有新X浏览、抓取、发布、互动、付费调用或新增依赖。34项标准库测试覆盖版本/事务、证据缺口、距离例外、弱材料与强题材分离、主动作、零/缺失率、错窗口/错正文/搜索指标排除、真实评论引用和重建一致性。旧seed audit仍是11链接13观察，与本轮派生覆盖和账号反馈不混算。
