# 来源支撑的原创测试帖

“一个转发顶几个赞”，这类 X 流量配方，第一步就读错了代码。

X 公开算法的权重，乘的是「这个读者点赞、转发的预测概率」，不是你已经拿到的互动数。

同一条帖，对不同读者，分数可以不同。

把排序公式当成互动兑换表，方向就错了。
