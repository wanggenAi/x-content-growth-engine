# 30-post learning experiment

更新：2026-10-06。30 条是一个学习容量上限，不是发布配额，也不是现在要填满的队列。设计记录见 `data/learning_experiment_30_2026-10-06.json`；当前 `PUBLICATION_PAUSED_FOR_LEARNING`，没有安排发布时间。

## 预注册字段

每个实验候选必须有 `experiment_id`、`candidate_id`、题材、来源、内容机制、素材强度、唯一 `primary_action`、预期读者、`why_share`、`why_reply`、`why_follow`、新颖度、payload、格式/媒体、发布时间（未知则 null）和 1h/6h/24h/72h/7d 观察窗口。缺字段就不能进入人工发布审查。

实验单元按强素材自然形成，不强行平均：现实利益/金钱、身份/处境、真实互联网发现、资源/工具、利益冲突、科技/AI、真实猎奇、历史/文化重释、强人物反差、可回答争议只是候选标签。标签不是机制结论。

## 设计约束

- 先预注册问题、主要指标和停止条件；一次只改变少量内容机制，保留反例和普通对照。
- 观察窗口未结束时不发布下一条同单元；高频连发不是默认策略。时间间隔作为待实验变量，不能先写成“最佳 X 小时”。
- 主要指标是相对本账号基线的窗口表现和主要动作率，绝对浏览只作为观察值。不得把相关性写成因果。
- F01–F05 继续 `HYPOTHESIS`；没有独立 holdout、反例和足够窗口不得升级。
- 任何一条若触发 editorial gate 失败、重复记忆或素材强度不足，直接淘汰/暂停，不为凑满 30 条替换旧稿。
