## P09 · 误关标签页

Chrome 页面被手滑关了？先别重搜。

Windows/Linux：Ctrl+Shift+T
Mac：⌘+Shift+T
可按关闭顺序逐个恢复。

这次可以撤回的，是手滑，不是人生。

https://support.google.com/chrome/answer/157179?hl=en

## P10 · 页内查找

打开长文只想找一个关键词？

Chrome：Windows/Linux 按 Ctrl+F，Mac 按 ⌘+F，输入关键词再跳到匹配处。

适合定位“限制”“价格”“要求”。鼠标滚轮终于不用跑马拉松了。

https://support.google.com/chrome/answer/157179?hl=en

## P11 · 保存研究标签

查资料开了一排 Chrome 标签，明天还想接着看？

按 Ctrl+Shift+D（Mac：⌘+Shift+D），把所有打开的标签存进一个书签文件夹。

文件夹取个主题名。别让浏览器替你经营一家百货商场。

https://support.google.com/chrome/answer/157179?hl=en

## P12 · 网页字体

网页字太小，先别把脸贴上去。

Chrome：Ctrl 和 + 放大，Ctrl 和 - 缩小，Ctrl+0 恢复默认。Mac 把 Ctrl 换成 ⌘。

调整的是页面缩放。你买的是电脑，不是显微镜。

https://support.google.com/chrome/answer/157179?hl=en

## P13 · 剪贴板历史

Windows 连续复制几段文字，总是忘了上一段？

按 Win+V，首次按提示开启剪贴板历史，再从历史里选择要粘贴的内容。

开启前没保存的内容不能靠它找回。密码别往这里囤，剪贴板不是保险柜。

https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec

## P14 · 区域截图

Windows 截图只想给别人看一个报错？

按 Win+Shift+S，框选那一块，再粘贴到消息里。

发之前看一眼有没有账号或聊天内容。求助需要报错，不需要给桌面办展览。

https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec

## P15 · 分屏

Windows 11 一边看教程、一边照着做：

按 Win+Z，选择贴靠布局，再把教程和操作窗口放到两边。

少一点来回切换。大脑已经在学东西了，就别顺便考它记忆力。

https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec

## P16 · 双屏移动

双屏用户：窗口开错屏，不一定要拖鼠标。

Windows 按 Win+Shift+→，把当前窗口移到右边显示器；向左用 ←。

窗口能搬家，鼠标也能少跑两趟。

https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec

## P17 · 快速预览

Mac 想看文件内容，先试试空格。

Finder 里选中文件 → 按空格预览 → 再按空格关闭。支持的图片、PDF 等都适合。

先看一眼再决定要不要打开，电脑也不想每次都盛装出席。

https://support.apple.com/en-sg/guide/mac-help/mh14119/mac

## P18 · 窗口截图

Mac 截图想只保留一个窗口？

⌘+Shift+4 → 按空格 → 点击目标窗口。
按住 Option 再点，可去掉窗口阴影。

不用先截整屏再裁。小截图，也可以有边界感。

https://support.apple.com/en-gb/102646

## P19 · 截图保存位置

Mac 桌面全是截图，像铺了一地纸？

macOS 10.14 及以后：⌘+Shift+5 → “选项” → 选择截图保存位置。

给截图一个固定文件夹。整理桌面的第一步，是别再往桌上扔。

https://support.apple.com/en-gb/102646

## P20 · 限定官方搜索

搜工具教程时，想先看官方说法：

Google 输入：
site:support.google.com/chrome 标签页

site: 后面别加空格。结果仍要点开核对。

先找说明书，少参加“我听说”接力赛。

https://support.google.com/websearch/answer/2466433?hl=en

## P21 · 搜索原句

看到一句话，想找原出处？

把其中独特的一段放进英文双引号，再搜：
"一段原句"

这是精确短语搜索；没结果可缩短。搜到转载也要继续追源。

引号能缩小范围，不能给传言发毕业证。

https://support.google.com/websearch/answer/2466433?hl=en

## P22 · 排除歧义

Google 搜一个词，却总跑到别的意思？

用减号排除：
jaguar speed -car

这是官方示例：找美洲豹速度时，排除汽车相关词。

先把同名选手请下台，搜索才能少串戏。

https://support.google.com/websearch/answer/2466433?hl=en

## P23 · 找PDF

想找一个主题的 PDF？

Google 输入：
主题 filetype:pdf

再看作者、发布机构和日期；PDF 只是一种格式，不是权威认证。

西装可以租，可信度不能。

https://support.google.com/websearch/answer/2466433?hl=en

## P24 · 找邮件附件

Gmail 找不到那份 PDF，先别翻到手酸。

搜索：filename:pdf
知道发件人，再加 from:对方邮箱。

缩小到附件类型和发件人，再核对内容。邮件不用一封封开盲盒。

https://support.google.com/mail/answer/7190?hl=en

## P25 · 找大邮件

Gmail 想找占空间的旧邮件？

搜索：
has:attachment larger:10M older_than:1y

筛出带附件、整封大于 10M、超过一年的邮件。先检查，别一键全删。

大文件里，也可能住着你的救命作业。

https://support.google.com/mail/answer/7190?hl=en

## P26 · 扩大邮件查找

Gmail 明明有过这封邮件，普通搜索却找不到？

试：in:anywhere 关键词

它也搜索垃圾邮件和回收站。找到后再核对发件人，不急着点附件。

“没看见”与“没收到”，差着两个文件夹。

https://support.google.com/mail/answer/7190?hl=en

## P27 · 冻结表头

Google Sheets 表格一滚动，就忘了这列是什么？

电脑版：视图 → 冻结 → 1 行，把首行表头固定住。

再往下看数据，标题还在。表头别下班，读表的人还在加班。

https://support.google.com/docs/answer/9060449?hl=en

## P28 · 拆分列

一列全是“姓名,城市”，想拆成两列？

Google Sheets 电脑版：先复制表格备份 → 选中该列 → 数据 → 将文本拆分为列 → 分隔符选逗号。

右侧留空列，再核对结果。逗号终于有了正式工作。

https://support.google.com/docs/answer/6325535?hl=en

## P29 · 清空格

表格里的“北京”和“北京 ”看着一样，却可能带着尾巴。

Google Sheets：选中范围 → 数据 → 数据清理 → 修剪空白。

先备份，再核对；不换行空格不在清理范围内。空格也有漏网之鱼。

https://support.google.com/docs/answer/6325535?hl=en

## P30 · 扫描PDF

iPhone 想把纸质资料存成 PDF，不必先找扫描 App。

备忘录 → 附件按钮 → 扫描文稿 → 对准纸张，检查边框 → 完成。可继续扫多页。

保存的是 PDF，重要数字仍要对照原纸。手机上岗，扫描仪先歇会儿。

https://support.apple.com/en-euro/guide/iphone/iph653f28965/ios

## P31 · 扫描文字

纸上几行字，不想重新打？

iPhone 备忘录 → 附件 → 扫描文本 → 对准文字 → 选中 → 插入。需设备和语言支持。

插入后检查数字、姓名和标点。识别负责搬运，核对负责别搬错家。

https://support.apple.com/en-euro/guide/iphone/iph653f28965/ios

## P32 · 分享精准段落

发长文给同事，想让对方直接看到重点？

电脑 Chrome：选中那段文字 → 右键 → 复制指向突出显示内容的链接。

部分页面不支持，发前试开一次。别给人一篇长文，再附赠一场寻宝。

https://support.google.com/chrome/answer/10256233?hl=en

## P33 · GitHub锁版本

引用 GitHub 文档，怕以后原文改了？

打开文件页面，按 y，再复制网址：链接会固定到当前提交版本。

适合记录“当时文档怎么说”。main 会向前走，证据最好留在原地。

https://docs.github.com/en/repositories/working-with-files/using-files/getting-permanent-links-to-files

## P34 · GitHub行链接

请人看 GitHub 代码，别只丢一个仓库地址。

点第一行行号 → 按住 Shift 点最后一行 → 行菜单选 Copy permalink。

把问题写在链接旁。让对方定位代码，不是考古。

https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/creating-a-permanent-link-to-a-code-snippet

## P35 · 阅读模式

Firefox 看长文，被按钮和背景打断？

地址栏有阅读模式图标时，点它；再调整字号、行宽。不是每个页面都支持。

先把阅读现场收拾干净，大脑就少逛几家路边摊。

## P37 · JSON格式化

有 Python 3，想把挤成一行的 JSON 展开？

终端运行：
python3 -m json.tool input.json

结果打印出来，原文件不改。能解析不等于符合业务要求。

排版治好了，业务逻辑还得自己看医生。

https://docs.python.org/3/library/json.html

## P38 · JSON中文

Python 格式化 JSON 后，中文变成一堆反斜杠？

Python 3.9+ 运行：
python3 -m json.tool --no-ensure-ascii input.json

让中文直接显示。它改的是输出表示，没替你翻译，也没给数据升学历。

https://docs.python.org/3/library/json.html
