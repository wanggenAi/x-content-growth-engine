# 根哥内容与执行规范

更新：2026-10-01。依据本聊天的用户明确要求。后续会话、机器与定时续跑开始时必须读取本文件、USER_DECISION_LOG.md、TASK_STATE.md 和 state/task_state.json；具体发布以清单和公开页面为准。

## 目标和选题

目标是账号内容更有吸引力、扩大自然传播，不是幽默本身，也不是仅完成发布数量。当前目标仍为新增200条原创，逐步推进；研究与核验不能用待研究选题代替已写稿。不得声称保证爆款、保证推流或已经验证传播公式。

选题保持广泛：社会小事、生活处境、利益和自我形象的反差、社会新闻、实操、政策原文、跨社区的新信息。人物不局限科学家和宏大励志故事；覆盖有知名度的中小创作者、抖音及其他平台主播、演员、明星、企业家、争议公共人物。特朗普、马斯克及OpenAI相关人物可研究，但每个事实必须核对具体对象和出处。用户口述的“Keybo”身份尚未确认，不猜测指代。

人物反差可来自旧观点与新观点、早年形象与后来处境、辉煌与低谷。历史死亡必须标日期；旧照片不能冒充近照；私生活、经济困境、死亡和犯罪传闻不能作事实。关注度不是可靠来源。

## 根哥语气

参考用户在聊天里的表达：直接、口语、具体、有自己的判断，喜欢追问“为什么”和利益落在哪里。把复杂事情说清楚，像跟人聊天。可以有锋芒和意外感，也可以用“说个暴论”开头；不机械堆“对吧、知道吧”。这是用户要求的写作风格，不是伪造亲历或替用户虚构立场。

避免训人、教读者做人和万能金句。少用“真正要…、你必须…、能…才…、这值得我们反思”；不强行升华，不每帖附同一段免责声明。不写机器人式排比或空洞大道理。优先用具体场景、原话、日期和矛盾；评论短一点，让读者看见作者在想什么。

发布前按人的阅读顺序读一遍：主语清楚、前后承接、句子通顺、无跳跃逻辑。去掉同义重复、重复段落和链接插入句子。读不顺就重写；不能用数量压力接受乱稿，不能把格式/正文失败解释成“不够吸引人”。

观点用观点的语气，事实给出处。“暴论”是开头形式，不是编造大多数人怎样的许可证；没有证据的普遍判断改为明确的个人看法或待验证猜想。第一人称可以表达判断，不能虚构作者经历、花费、测试、关系或结果。

不照搬别人爆帖。参考上万浏览的直接可见案例及反例，提炼结构；索引发现线索与直接指标分开。GitHub、Reddit、LINUX DO及跨平台资料可寻找方法和素材，仍遵守权利与采集边界。

## 发布核验：失败即修复

1. 来源与正文核对、去重、长度检查完成后再打开编辑器。优先原生粘贴；2026-10-01的逐字键盘输入曾丢失中文，仅留下数字和引号，禁止未经核验复用。
2. 读取真实编辑器全文并截图，逐句与待发稿比对；检查中文、重复段落、首尾句、引号、换行、链接及卡片。不能只看按钮启用。DOM改字但未被编辑器接收的办法不能提交；反复试错不得产生额外公开帖。
3. 提交一次，保留发送提示，再重新加载独立公开详情链接。核对发布全文、来源链接、账号、时间及截图，确认无缺字或重复才标PUBLISHED_AGENT_VERIFIED。发送提示不等于正文核验。
4. 异常先停新帖并修复。编辑可能生成新的版本URL：保留原始URL、失败版本、最终URL和核验时间；编辑不是新增帖子。无法修复时如实记录，不能增加完成数。

本地Browser Harness优先用于允许的研究、导航和读取；账号提交/更新仍走已经记录的可见Computer Use方法边界。工具失败或规则限制不得靠切换工具绕过。没有付费API、云平台、Cookie、隐藏接口或新社交自动化软件。

## 互动、统计和接续

用户授权与内容有关的自然交流和中性回复。只在读懂原帖后给具体补充或回应；不批量复制评论，不制造互动，不宣称“活跃就能推流”。没有以话题人物为目标的骚扰、传闻或攻击。

不专门花时间持续监控本账号流量，用户会看X自带统计；仅在有助于调整内容时查看少量必要反馈。不能凭几次浏览推断机制。

每轮新要求、新结论、失败修复和产出都落仓库：决策摘要进USER_DECISION_LOG.md；当前断点进两份状态；正文、真实URL、版本和缺失值进发布清单；截图、原始账号记录留ignored data/private/。公开仓库不上传聊天原始私密记录。运行适当检查并提交推送；新机器先恢复这些文件再继续。
